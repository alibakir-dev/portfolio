01 · Jameson

Jameson Football EPL Loyalty Campaign

A live-results reward campaign for a spirits brand and its football fans.

  • SFMC Automation Studio
  • API
  • SQL
  • SSJS

Problem

Run a loyalty campaign tied to live match results.

What I did

I designed the mechanic, pulled results from a score API on a schedule, and sent winning-team fans an email with a single-use discount code.

Hard part

Twice-weekly runs risked duplicate emails, so I added a unique weekly ID. I normalized mismatched team names, bulk-fixed old records with SQL, and enforced one code per person.

02 · Jameson

Closest Pub Finder

A real-time tool that connects website visitors with nearby partner venues.

  • Cloud Pages
  • SSJS
  • Haversine
  • Data Extensions

Problem

Help users find a partner venue near them from a brand website.

What I did

I built an iframe page that takes a postcode and lists the five nearest venues using the Haversine formula. It emails the selected venue, address, map link, and a discount code.

Hard part

The result had to update in real time and let users change their venue later without breaking the reward journey.

03 · Pernod Ricard UK

Large-scale postcode enrichment

Location data cleanup across a contact table of up to two million records.

  • SSJS
  • SQL
  • FTP
  • Batch processing

Problem

UK postcodes and city names were not standardized across a large contact table.

What I did

I imported a public five-million-row postcode file in chunks over FTP, then used SSJS and the Haversine formula to find the nearest cities and update contacts.

Hard part

I excluded edge cases where the nearest city was in a neighboring country and processed records in batches to avoid timeouts.
