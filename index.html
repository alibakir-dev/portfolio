01

Jameson Whiskey

Jameson Closest Pub Finder

A real-time location tool connecting website visitors with nearby partner pubs and instant rewards.

  • CloudPages
  • SSJS
  • Haversine
  • Data Extensions

Problem

Help website visitors find a nearby partner venue and claim a reward offer in a smooth, real-time flow directly from the brand's website.

What I did

I built a CloudPage embedded as an iframe on the brand site. When a user entered their postcode, I used partner coordinates and the Haversine formula to list the five closest venues, validate postcode formats, and email the chosen venue's address, map link, and reward code.

Hard part

Distance lookups had to run in real time on every submit with no batch window, while cleanly handling invalid postcodes and allowing users to change their selected venue later without breaking the reward flow.

02

Jameson Whiskey

Jameson Football EPL Loyalty Campaign

A live-results reward campaign reacting to weekly league matches for Jameson Whiskey fans.

  • SFMC Automation Studio
  • REST API
  • SQL
  • AMPScript

Problem

Design a campaign mechanic from scratch before the league season that reacted to real match results, rewarded fans of winning teams, and prevented duplicate claims.

What I did

I paired favorite-team data from our Preference Center with a third-party league API. Scheduled Automation Studio runs pulled match winners and automatically emailed winning-team fans a single-use venue voucher.

Hard part

Irregular match days required twice-weekly runs. I prevented duplicate sends with a weekly match ID in the Data Extension primary key, bulk-fixed mismatched team names with SQL, and enforced one code per fan using RaiseError and segment exclusions.

03

Pernod Ricard Brands

Large-Scale Postcode Enrichment

Location data standardization across a contact table of up to two million records.

  • SSJS
  • SQL
  • FTP
  • Batch Processing

Problem

UK postcodes and city definitions lacked a clean standard across a Data Extension of roughly 1–2 million contacts that needed a reliable nearest-city value.

What I did

I imported a published 5-million-row UK government area-code CSV into the Business Unit and wrote an SSJS script using the Haversine formula to calculate nearest cities and update the master contact table in batches.

Hard part

The 5-million-row CSV was too large for a single import, so I split it over FTP. I also filtered out border postcodes that matched cities in neighboring countries and batched the SSJS updates to avoid script timeouts.

Also built: an API-driven personalized image campaign across five brand sites, and a mobile game score-and-reward email integration.
